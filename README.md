# N7 Banking

A premium, state-of-the-art corporate banking and compliance solutions landing page designed with rich visual aesthetics, dynamic micro-interactions, and a sleek dark-mode interface. 

Built using **React**, **Vite**, **Tailwind CSS**, and **TypeScript** for absolute visual precision, lightning-fast rendering, and smooth responsive flow.

---

## 🌟 About the Project

**N7 Banking** represents a modern corporate finance and treasury experience. It showcases high-fidelity interactive sections explaining digital banking infrastructure, automated compliance checks, and cross-border payment solutions. 

### Key Modules & Components:
- **Hero & Navbar:** A stunning introduction screen combined with a floating responsive navigation bar that features hover-triggered active indicators.
- **TrustedBy & Marquee:** A scrolling marquee displaying high-fidelity SVGs of brand partners with seamless loop animations.
- **Core, Connected & Digital Banking:** Highly detailed feature grids explaining instant KYC/AML verification, multi-currency processing, and global financial operations.
- **Insights Showcase:** An interactive case-study and article carousel utilizing multi-layered cards and premium custom micro-animations.
- **Paperless CTA:** A striking, dark-accented call-to-action zone directing users to custom product portals.

---

## 📱 Responsiveness & Device Support

The layout is built with a **fluid mobile-first philosophy** designed to feel premium and work flawlessly on all form factors—from ultra-wide 4K monitors to pocket-sized mobile screens.

### Key Responsive Design Pillars:
* 🌐 **Fluid Breakpoint Grid:** Uses Tailwind CSS responsive breakpoint modifiers (`sm:`, `md:`, `lg:`, `xl:`, `2xl:`) to adapt layouts from multi-column grids to structured vertical stacks dynamically.
* 📐 **Vector Accuracy:** Custom star, arrow, and corporate partner SVGs are built inline with viewBox mappings, guaranteeing crisp scaling and eliminating clipping on high-density Retina or OLED displays.
* 🖐️ **Touch-Friendly Interactivity:** Buttons, sliders, navigation links, and carousel elements feature expanded hit targets and tap states tailored for touch devices.
* ✍️ **Fluid Typography:** Heading and body text uses responsive typography sizes (`text-3xl lg:text-5xl`) to maintain high-impact editorial layouts and comfortable readability regardless of window dimensions.

## 🚀 Quick Start

Follow these simple steps to set up and run the project locally.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) and **npm** installed on your system.

### 1. Install Dependencies
Navigate to the project root directory and install the required npm packages:
```bash
npm install
```

### 2. Run the Development Server
Start the local development server:
```bash
npm run dev
```
Once started, open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
